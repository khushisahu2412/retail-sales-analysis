# Retail Sales Analysis Dashboard

## Project Overview
This project analyzes retail sales data using SQL and Power BI to understand revenue, profit, category performance, and city-wise sales.

## Tools Used
- Microsoft Excel
- SQL
- PostgreSQL
- Python
- Microsoft Power BI
- DAX measures

## Dashboard Features
- Total Revenue KPI
- Total Profit KPI
- Revenue by Category
- Revenue by City
- Profit by Category
- Revenue Trend by Year
- Profit by City

## Key Results
- Total Revenue: 380K
- Total Profit: 98K
- Highest-revenue category: Electronics
- Highest-revenue city: Pune

## Project Files
- Power BI dashboard (`.pbix`)
- Dashboard screenshot (`.png`)

## Purpose
Created as a portfolio project to practice SQL-based data analysis and Power BI visualization.
